# Assets

Production art, audio, fonts, tilesets, portraits, and animation sources belong here.

## Current state

Vertical-slice v2 intentionally uses procedural Godot drawing and fallback fonts. No production visual asset set is required to exercise the current loop.

The first asset pass should begin after human interactive acceptance identifies which spatial, character, interaction, and feedback cues need the most improvement.

## Repository policy

- commit small runtime-ready assets normally
- use Git LFS for large editable source masters when size warrants it
- do not commit duplicate downloads, temporary renders, export folders, or local caches
- preserve source attribution and license information for third-party assets
